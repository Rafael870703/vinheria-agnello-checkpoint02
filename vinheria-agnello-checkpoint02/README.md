#  vinheria-agnello-checkpoint02

## Descrição
Sistema de avaliação de estoque e tendência de vinhos da Vinheria Agnello, feito com `prompt()` e `alert()`.

No Checkpoint 02 foi implementado:
- Cadastro de vários vinhos em sequência (pergunta ao final se deseja cadastrar outro)
- Funções reutilizáveis: validação de entradas, estoque baixo (< 5), classificação (jovem, amadurecido, antigo) e exibição no console com `alert()`
- Resumo final: total de cadastros, vinhos com estoque baixo e vinho com a safra mais antiga
- Sem arrays ou objetos: variáveis numeradas (`nome1`, `safra1`, `quant1`...)
